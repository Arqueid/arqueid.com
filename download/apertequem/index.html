Sobre o Programa

O Aperte Quem é um software simulador de urna eletrônica desenvolvido para recriar a experiência de votação de forma prática e intuitiva. É ideal para simulações escolares, eleições internas de grêmios, treinamentos ou demonstrações didáticas.

Nota: O programa é disponibilizado compactado no formato .RAR. Certifique-se de ter um programa de extração instalado no seu computador, como o WinRAR ou 7-Zip.

Como Baixar e Instalar

  1. Faça o Download: Clique no botão verde de download acima para baixar o arquivo salvo no Catbox.
  2. Localize o Arquivo: Após o término do download, navegue até a pasta de Downloads do seu dispositivo.
  3. Extraia o Arquivo: Clique com o botão direito do mouse sobre o arquivo baixado (.rar) e selecione a opção "Extrair Aqui" ou "Extrair para...".
  4. Executar o Programa: Abra a pasta extraída e execute o arquivo principal (geralmente com extensão .exe) para iniciar a Urna Eletrônica. Não é necessária instalação complexa.

Como Usar o Simulador

O funcionamento da interface replica os passos da urna oficial. Veja as principais funções dos botões e teclado:

Tecla / Botão Função
Teclas Numéricas (0 a 9) Digitam o número do candidato desejado.
CONFIRMA (Verde) Confirma o voto no candidato exibido na tela ou finaliza a votação.
CORRIGE (Laranja/Vermelho) Apaga os números digitados para reiniciar a digitação.
BRANCO Registra o voto em branco.

Dicas para Configuração da Eleição

Para cadastrar novos candidatos, fotos e cargos na simulação, verifique os arquivos de texto ou o painel de configurações dentro da pasta do programa extraído antes de iniciar a votação com os eleitores.
