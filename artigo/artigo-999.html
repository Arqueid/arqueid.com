Como Ejetar HD Externo com Script Batch no Windows

Publicado em: 30 de Outubro de 2026

Para automatizar e simplificar a remoção segura de unidades de armazenamento USB, é possível utilizar um script em Batch (.bat) que invoca diretamente a interface nativa do Windows responsável pela gestão de dispositivos de ligação a quente.

O código abaixo configura o ambiente do terminal e executa a ferramenta de ejeção de hardware, apresentando simultaneamente instruções claras ao utilizador: 

@echo off
title EJETAR HD EXTERNO
color 0B

start "" rundll32.exe shell32.dll,Control_RunDLL hotplug.dll

echo.
echo 1. Localize sua case USB na lista.
echo 2. Selecione o dispositivo.
echo 3. Clique em Parar ou Remover.
echo 4. Aguarde a confirmacao do Windows.
echo.
echo Nao desconecte antes da confirmacao.
echo ==========================================
pause

Instruções de Implementação: Copie o bloco de código acima, crie um ficheiro de texto plano, cole o conteúdo e guarde o documento com a extensão .bat. A execução deste ficheiro abrirá a janela de remoção segura de hardware do sistema operativo de forma imediata.
