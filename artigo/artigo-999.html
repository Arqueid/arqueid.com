Como Forçar a Ejeção de Discos via CMD no Windows

Publicado em: 30 de Outubro de 2026

Em diversas situações, o Windows impede a remoção segura de um pendrive, HD externo ou cartão de memória informando que a unidade está sendo usada por outro programa. Para contornar esse travamento de forma rápida e direta, é possível utilzar um comando nativo via Prompt de Comando (CMD) executado como Administrador.

Para realizar a ejeção forçada sem a necessidade do PowerShell, siga o passo a passo abaixo:

1. Abra o menu Iniciar, digite cmd, clique com o botão direito sobre "Prompt de Comando" e selecione Executar como administrador.

2. Cole o seguinte comando na janela do CMD, lembrando de substituir a letra F pela letra da sua unidade: 

(echo select volume F & echo remove all noerr dismount) | diskpart && echo Disco ejetado com êxito!

3. Pressione Enter. O utilitário diskpart desmanchará a montagem da unidade e, caso a operação seja concluída com sucesso, a mensagem "Disco ejetado com êxito!" será exibida no terminal.

Este método utiliza a ferramenta nativa de gerenciamento de discos do Windows (Diskpart) combinada com executores de cadeia de comandos, permitindo liberar o volume com segurança diretamente no nível de sistema.
